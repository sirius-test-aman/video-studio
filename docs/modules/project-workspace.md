# Cross-cutting: Project Workspace

Every module operates inside a project, and a project is what binds Velox to a
Jira project and a Confluence space.

---

## What it does

Select an existing project from **My Project**, or create one with **New Project**
by supplying a project name, a Jira project from a dropdown, and a Confluence
space from a dropdown. Created projects appear in My Project with their linked
Jira and Confluence shown.

The link is what enables bi-directional sync and gives every session inside the
project real context.

## Why it matters for videos

- **Every tutorial repeats this.** Login, workspace, project selection are the same three steps in all of them.
- **No promo should include it.** A promo opens at the moment of value.
- Because the narration is identical across tutorials, reusing those lines verbatim hits the audio cache and costs nothing. See CLAUDE.md on content-addressed audio.

## What is genuinely true

- One project links to one Jira project and one Confluence space.
- The link enables bi-directional sync.
- Project context is what grounds sessions inside that project.

## What we do not claim

- Do not imply a project can span multiple Jira projects or Confluence spaces.
